# Evidencias – Infraestructura 3

Esta carpeta corresponde a las evidencias obtenidas durante la
implementación y validación de la Infraestructura 3.

Las evidencias documentadas incluyen:

- Topología implementada en GNS3.
- Interfaces de R-USER.
- Configuración de VLAN 10.
- Asignación de direccionamiento mediante DHCP.
- Interfaces WAN y SERVER del FortiGate.
- Conectividad entre R-USER y FortiGate.
- Conectividad entre FortiGate y WEB-SERVER.
- Pruebas de direccionamiento y enrutamiento.
- Troubleshooting realizado durante la implementación.

Las capturas y su explicación detallada se encuentran incluidas
en la documentación técnica del repositorio.
